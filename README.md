# ATELIER-SYMFONY-RoutinG-CONTR-LEUR

Symfony project for routing and controller exercises.

## Summary

- Symfony application structure
- Routes defined using PHP attributes
- Controller examples in `src/Controller`
- Twig templates in `templates`

## Getting Started

1. Install dependencies:
   ```bash
   composer install
   ```

2. Run the Symfony local server:
   ```bash
   symfony server:start
   ```

3. Open the app in your browser at `http://localhost:8000`

## Notes

This project includes examples for route parameters and controller redirects.
